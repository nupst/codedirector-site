CodeDirector

Turn codebases and technical docs into narrated tutorial videos.

What CodeDirector is

CodeDirector is a Windows desktop application for solo developers, educators, and open-source maintainers. It takes a codebase and its documentation, plans a step-by-step programming lesson, replays the coding steps deterministically inside Visual Studio Code and a browser, and then adds AI voice-over, camera moves, a cursor overlay, and subtitles to render a finished programming-tutorial video — so a creator can produce a YouTube-style coding tutorial without recording their screen or speaking on camera.

Why CodeDirector uses YouTube access

After CodeDirector renders a tutorial video on the creator's own computer, its optional Publish feature lets the creator upload that video directly to their own YouTube channel. To do this, CodeDirector requests the https://www.googleapis.com/auth/youtube.upload scope from the YouTube Data API v3. This scope is used for one purpose only: to upload the finished video file — with the title, description, and tags the creator entered — to the creator's own channel, only when the creator explicitly clicks “Publish”.

The creator signs in to their own Google account in their own browser. CodeDirector never sees the account password, runs entirely on the creator's computer with no server or backend, and stores the OAuth authorization tokens only in a local file on that same computer. CodeDirector does not read the creator's videos, subscribers, comments, watch history, or analytics.

TikTok publishing

The same optional Publish feature can post the finished video to the creator's own TikTok account through TikTok's official Content Posting API (video.publish scope), following the identical sign-in-in-your-own-browser, tokens-stored-locally model.
